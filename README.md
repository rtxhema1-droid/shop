# RTX SHOP

متجر إلكتروني مصري كامل (Next.js 16): الدفع عند الاستلام، العملة جنيه مصري، الشات بيتحوّل على واتساب (`+20 120 360 1981`)،
أقسام وأقسام فرعية، عمولة بتحددها إنت لكل منتج، ولوحة تحكم للمالك والتجار.

## الرفع على Vercel (5 دقايق)

1. ارفع المجلد ده على GitHub (أو اسحبه على Vercel مباشرة).
2. في Vercel: **Add New → Project** واختار المشروع. (مفيش إعدادات بيلد خاصة).
3. **مهم:** من تبويب **Storage** اعمل قاعدة بيانات **Postgres (Neon)** واربطها بالمشروع — هيتضاف المتغير `DATABASE_URL` لوحده.
   من غير قاعدة البيانات الداتا مش هتتحفظ (Vercel مش بيحتفظ بملفات على السيرفر).
4. اعمل **Redeploy**. أول فتحة للموقع بتعمل الجداول والأقسام والمحافظات وحساب المالك أوتوماتيك.

> نصيحة سرعة: خلّي Region الـ Functions قريب من الداتابيز (Settings → Functions).

## حساب المالك

- بيتعمل مرة واحدة بس لما الداتابيز تبقى فاضية، من المتغيّرات `OWNER_USERNAME` و `OWNER_PASSWORD`.
- لو `OWNER_PASSWORD` فاضي أو أقل من 10 حروف، بتتولّد كلمة سر عشوائية وتتطبع مرة واحدة في لوج السيرفر (Vercel ← Logs).
- **حط كلمة سر قوية قبل أول تشغيل، وغيّرها من لوحة التحكم ← حسابي.** لو حسابك قديم وبكلمة السر الافتراضية القديمة هيظهرلك تنبيه أحمر في اللوحة لحد ما تغيّرها.

## اللي في اللوحة

| الصفحة | بتعمل إيه |
|---|---|
| المنتجات | إضافة/تعديل/إخفاء، رفع صورة (بتتصغّر أوتوماتيك)، سعر قبل الخصم، مخزون، **عمولتك % لكل منتج** (تعديل سريع من القايمة) |
| الأقسام | أقسام رئيسية وفرعية (مثلاً: الأجهزة الإلكترونية ← سماعات / ساعات ذكية…) إضافة وتعديل ومسح |
| التجار | حسابات تجار بصلاحيات (منتجات / عرض الطلبات / تحديث الطلبات) |
| الشحن | سعر الشحن لكل محافظة |
| العمولات | رصيدك وسجل العمولات (بتتحسب لما الطلب يتسلّم) |
| الطلبات | قبول / رفض / تم التسليم + واتساب العميل |

العمولة بتتثبّت على الطلب وقت الشراء، يعني لو غيّرت النسبة بعدين الطلبات القديمة مش بتتأثر.
منتجات التاجر الجديد عمولتها الافتراضية 10% لحد ما تعدّلها، ومنتجاتك إنت عمولتها 0%.

## تشغيل على جهازك

```bash
npm install
npm run dev      # من غير DATABASE_URL بيستخدم SQLite محلي (محتاج Node 22.5+)
```
لو حطيت `DATABASE_URL` في `.env.local` هيشتغل على Postgres.

## ملاحظات

- رقم الواتساب في `lib/config.ts`.
- حذف المنتج «إخفاء» عشان الطلبات القديمة تفضل سليمة.
- تم حذف شات الـ AI القديم (كان بيبعت رسايل العملاء لخدمة خارجية بمفتاح ثابت في الكود).

## الصور (اختياري: Vercel Blob)
- من غير إعداد: الصور بتفضل في الداتابيز، لكن بتتقدّم WebP مصغّرة حسب الشاشة (`/api/products/:id/image?w=480|800|1200`) مع كاش طويل.
- مع `BLOB_READ_WRITE_TOKEN`: الصور الجديدة بتتخزن في Blob بـ 3 أحجام WebP.
- نقل الصور القديمة على دفعات (للمالك فقط، آمن للتكرار): `POST /api/images/migrate` بجسم `{"limit": 10}` وكرر لحد ما `remaining` تبقى 0. الصور القديمة بتفضل شغالة لحد ما تتنقل.
